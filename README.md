# matthaeusheer's NixOS Config

### My NixOS system, configured declaratively via home-manager.

## What Software Am I Using?

- Channel: NixOS 26.05 (channels, not flakes — deliberately simple)
- Package manager: `nix` + `home-manager` (as a NixOS module)
- Desktop: GNOME
- Terminal: `kitty`
- Shell: `zsh` + `oh-my-zsh`
- Prompt: `starship`
- Editor: `neovim` + `coc.nvim`

## Layout

```
hosts/
  nixos/
    configuration.nix          # system-level config for this machine
    hardware-configuration.nix # generated by the NixOS installer
home/
  home.nix                     # slim aggregator: identity + imports
  apps/
    git.nix
    zsh.nix
    kitty.nix
    starship.nix
    nvim.nix
```

One file per tool under `home/apps/`, each a self-contained home-manager module. `home/home.nix`
just wires them together — no per-tool config lives there. `hosts/<name>/` holds the system-level
side (currently just one machine, `nixos`), kept separate from `home/` so a second machine can reuse
the same `home/` config later without duplicating it.

`/etc/nixos/configuration.nix` and `/etc/nixos/hardware-configuration.nix` are symlinks into
`hosts/nixos/` — that's what lets a plain `sudo nixos-rebuild switch` (no flags) pick this repo up
directly.

## Bootstrap a New Machine

1. Install NixOS from a USB image.
2. Clone this repo, e.g. to `~/code/nix`.
3. Add the home-manager channel (match the branch to your NixOS version):
   ```bash
   sudo nix-channel --add https://github.com/nix-community/home-manager/archive/release-26.05.tar.gz home-manager
   sudo nix-channel --update
   ```
4. Either add a new `hosts/<hostname>/` directory (copy `/etc/nixos/hardware-configuration.nix` into
   it, adjust `configuration.nix` as needed) for a new machine, or reuse `hosts/nixos/` if it's the
   same one.
5. Symlink the host config into place:
   ```bash
   sudo ln -sf ~/code/nix/hosts/<hostname>/configuration.nix /etc/nixos/configuration.nix
   sudo ln -sf ~/code/nix/hosts/<hostname>/hardware-configuration.nix /etc/nixos/hardware-configuration.nix
   ```
6. `sudo nixos-rebuild switch`
